# Triage labels

The live label inventory checked during import on 2026-10-11 contained `bug`,
`enhancement`, `wontfix`, `accessibility`, `documentation`, `duplicate`,
`good first issue`, `help wanted`, `invalid`, and `question`. Re-read labels before
any triage write; this list is an import snapshot, not a permanent configuration.

Use `bug` and `enhancement` for their matching category roles and `wontfix` for
the matching state. The upstream `needs-triage`, `needs-info`, `ready-for-agent`,
and `ready-for-human` state labels are not configured. Do not equate `question`
or `help wanted` with one of those states. Report proposed states in local drafts
until a requested triage/setup task establishes the missing mapping. Never
create or rename labels merely to install skills. Preserve unrelated labels.
