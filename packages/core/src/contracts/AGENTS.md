# Portable contracts

Read [the portable layer guide](../../docs/contracts.md) and the relevant gameplay spec.
Keep structural schemas, serializable contracts, collection membership and units
independent of content, gameplay rules, bundled mods and the default game.
A valid string ID does not prove registry membership. Preserve wire/save shapes
and collection membership semantics for authoritative ECS and prediction snapshots.
Run affected contract, protocol and geometry tests and report actual checks.
