## Generation prompt

Use case: stylized-concept. Create production game sprite sheet for Emberfall:
Marta the Innkeeper, a friendly middle-aged medieval woman NPC. Match existing
wardrobe-style RPG characters: carefully painted pixel-like clusters, warm
restrained walnut/ochre/moss palette, dark brown outlines, dimensional soft
material shading, compact sturdy proportions with large readable head, top-down
three-quarter overhead camera looking toward her front. Brown hair in bun,
warm burgundy-brown dress, cream apron, small belt pouch, sturdy brown boots,
relaxed friendly smile and hands resting near apron. No weapons. Canvas exactly
512 x 128 pixels if possible. Exactly four equal square cells, one horizontal
row. Same full-body front-facing woman in all four cells, identical size,
identical planted feet and bottom-center pivot; no walking, no turning, no
gestures, no camera movement. Idle animation only: frame 1 neutral eyes open,
frame 2 tiny chest breathing rise, frame 3 brief blink with eyes closed, frame 4
return to neutral. Each full body centered inside its cell with generous
transparent margins. Keep boots fixed and every costume detail identical across
frames. Genuine transparent alpha background. No ground plane or floor shadow,
no text, no labels, no grids, no borders, no checkerboard painted into image,
no scenery, no extra objects. Character should occupy approximately 100 of each
128 pixel cell's height and 65 pixels width. Clean usable independent sprites.
