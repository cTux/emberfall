# Generated equipment examples

These PNGs are unchanged copies of the generated Emberfall equipment slot and
warrior weapon art in `packages/client-new/public/assets/wardrobe-style`. Local
copies keep Storybook independent of the game client. They replace library item
icons in the equipment examples.

The original generation prompts and provenance are recorded in
[the wardrobe asset README](../../../../client-new/public/assets/wardrobe-style/README.md).
The art follows that collection's CC BY-SA 3.0 terms. Preserve the original
[credits](../../../../client-new/public/assets/LPC-CREDITS.txt) and
[license](../../../../client-new/public/assets/LPC-LICENSE.txt).
