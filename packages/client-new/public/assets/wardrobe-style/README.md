# Animated wardrobe-style assets

Generated with built-in imagegen on 2026-10-04 from the approved Emberfall concept sheets and the existing wardrobe reference. This directory contains generated source sheets plus mechanically cropped 96px weapon, status and portrait icons. Runtime atlas packaging preserves source artwork, trims transparent margins, maps measured row/column boundaries, and uses nearest-neighbor sampling. Actor rows are idle, four locomotion frames, windup, release, fallen. The four player classes now use separate four-pose walk sheets with stronger leg motion. Runner and caster retain three unique walk poses with one passing pose reused. Idle breathing, hurt flashes and enemy death fades are procedural presentation; locomotion and attacks use painted frames. Animal directions use horizontal reflection. These are a first integrated art pass, not hand-cleaned final animation.

Reference: LPC Wooden Furniture by bluecarrot16, Baŝto, Lanea Zimmerman (Sharm), William Thompson, Tuomo Untinen (Reemax), and Janna/Lilius/Jannax. https://opengameart.org/content/lpc-wooden-furniture . The original wardrobe crop and full source credits are retained under ../LPC-README.md, LPC-CREDITS.txt and LPC-LICENSE.txt. Wardrobe-derived artwork in this collection is distributed under CC BY-SA 3.0 with those notices. Other existing asset licenses remain alongside the original assets.

Preview: run the new client and visit /?art-gallery . The gallery shares the game's actual atlas loader and animation selector. Static buildings and terrain remain static; existing world geometry, lighting, foliage sway, damage and save rules are unchanged. Font and audio assets are unchanged.
